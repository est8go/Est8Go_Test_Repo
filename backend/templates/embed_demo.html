Quick Start

One tag. Done.

Copy this snippet, replace your-agency-slug with your slug, and paste it anywhere in your HTML.

HTML 
<script
  src="{{ base_url }}/static/embed.js"
  data-tenant="your-agency-slug"
  data-theme="auto"
  data-limit="6"></script>
How It Works

Three seconds to embed.

1
Find your agency slug
Your slug is the last part of your Est8Go vault URL — e.g. if your vault is at est8go-api.onrender.com/public/bravieshomz-limited then your slug is bravieshomz-limited.
2
Paste the script tag
Add the script tag to any page — inside the body, in a widget area, or in a code block. No backend changes needed.
3
Your listings appear instantly
The widget fetches your verified listings, renders them in a sandboxed Shadow DOM (so your site's CSS can't interfere), and auto-refreshes every 30 minutes.

Configuration

All data attributes.

Every attribute is optional except data-tenant.

Attribute Values Default Description
data-tenant your-slug — Required. Your agency slug from your Est8Go vault URL.
data-theme light · dark · auto auto Widget colour scheme. auto follows the visitor's OS preference and updates live.
data-limit 1 – 24 6 Maximum number of property cards to show. Listings are sorted by trust score (highest first).
data-type land · house · apartment · … all Filter by property type. Match your listing types exactly.
data-location maitama · lekki · … all Filter by location name (partial match, case-insensitive).

FAQ

Common questions.

Will the widget slow down my website?
No. The script loads asynchronously and uses Shadow DOM — it has zero impact on your page's CSS or layout until it renders. Images are lazy-loaded.
Do I need to log in or create an API key?
No. Your agency slug is all that's needed. The API only returns verified listings — it never exposes private data.
Can I embed multiple widgets on the same page?
Yes. Each script tag creates an independent widget with its own Shadow DOM. You can show different property types or locations side-by-side.
How do I get my agency slug?
Your slug is in your Est8Go vault URL. If your vault is at /public/bravieshomz-limited, your slug is bravieshomz-limited. Contact your Est8Go administrator if you are unsure.
What happens when I add new listings?
The widget auto-refreshes every 30 minutes. New verified listings appear automatically — no changes to your website code required.
