ACE Nigeria · Kora

Pilot data structure

The information Kora must retain to capture, qualify, hand off, and follow up on WhatsApp enquiries. A record is one saved entry for one thing.

Required for the Must-have pilot flow

1. Agency Must

The pilot agency whose enquiries Kora handles.

  • Agency ID
  • Agency name
  • WhatsApp business number
  • Operating hours and time zone
  • Active/inactive status
  • Date created and last updated
2. Team member Must

An agency employee who can own a lead or a follow-up.

  • Team member ID
  • Agency ID
  • Full name
  • Role
  • Work contact used for notifications
  • Active/inactive status
  • Date created and last updated
3. Buyer contact Must

The person who sends the WhatsApp enquiry.

  • Buyer contact ID
  • Agency ID
  • WhatsApp phone number
  • Name, when supplied
  • Date first seen and last updated
4. Lead Must

The agency’s working record for one buyer enquiry.

  • Lead ID
  • Agency ID
  • Buyer contact ID
  • Current status
  • Current assigned team member ID
  • First enquiry time
  • First-response time
  • Last customer-message time
  • Last agency/system-response time
  • Next follow-up due time
  • Closed time and closure reason
  • Date created and last updated
5. Conversation message Must

One message exchanged in the WhatsApp conversation.

  • Message ID
  • Lead ID
  • Sender
  • Message text or supported attachment reference
  • Direction: incoming or outgoing
  • Sent/received time
  • Delivery state, if available
  • Whether it was an automatic acknowledgement or qualification question
6. Qualification answer Must

One answer collected from the buyer during qualification.

  • Qualification answer ID
  • Lead ID
  • Question name
  • Answer value
  • Whether the answer is required
  • Time captured
  • Source
7. Lead assignment Must

The handoff of a qualified lead to the person responsible for acting on it.

  • Assignment ID
  • Lead ID
  • Assigned team member ID
  • Assigned by
  • Assigned time
  • Assignment state
  • Reason or routing note
8. Follow-up task Must

The specific next action an assigned team member must take for a lead.

  • Follow-up task ID
  • Lead ID
  • Owner team member ID
  • Task description
  • Due time
  • Task state
  • Completed time
  • Completion note or next action
  • Date created and last updated
9. Reminder / notification Must

A recorded alert about a new assignment or overdue follow-up.

  • Notification ID
  • Recipient team member ID
  • Related lead ID
  • Related follow-up task ID
  • Notification type
  • Delivery channel
  • Scheduled time and sent time
  • Delivery state

Needed for Should-have features

10. Lead activity Should

A time-stamped record of important changes to a lead.

  • Activity ID
  • Lead ID
  • Activity type
  • Person or system that made the change
  • Before and after values, where relevant
  • Time of change
11. Pilot configuration Should

Agency-specific settings used to tailor Kora without changing the product.

  • Configuration ID
  • Agency ID
  • Approved first-response message
  • Qualification questions and required/optional status
  • Team routing rules
  • Default follow-up due-time rule
  • Configuration version, active status, and last updated time

Could-have feature

12. Inspection appointment Could

An optional future appointment created from a qualified lead.

  • Appointment ID
  • Lead ID
  • Assigned team member ID
  • Proposed and confirmed date/time
  • Meeting location or property reference
  • Appointment state
  • Notes
Source: Kora Pilot Requirements
